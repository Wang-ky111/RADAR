# RADAR: Robust AI-Generated Image Detection via Dual-Domain Disentangled Representation

## 1. Core Contributions

- **Adaptive Frequency Masking**: Dynamically identifies and suppresses redundant frequency components with lower discriminative power, compelling the detector to leverage informative spectral cues for robust detection.

- **Intra-domain Disentangled Representation Learning**: Extracts compact, diverse, and complementary forensic features from each representation domain (spatial and frequency) through K=4 disentangled components, reducing redundancy while preserving task-relevant information.

- **Attention-aware Inter-domain Feature Fusion**: Explicitly models the interaction between spatial and frequency representations through a MixBlock and multi-scale attention mechanism, adaptively emphasizing informative cross-domain features.

- **Strong Cross-generator Generalization**: Extensive experiments demonstrate that RADAR achieves state-of-the-art detection performance across heterogeneous generative models and maintains improved generalization to images generated by unseen models.

## 2. Method Architecture

RADAR consists of three complementary stages:

### Stage 1: Adaptive Frequency Masking
- Input image X → FFT → complex spectrum X̃
- Magnitude Γ = |X̃| → log compression S = log(1+Γ)
- Adaptive average pooling V = P(S) → lightweight scoring network Q = Ψ(V)
- Coarse binary mask M̃ (lowest r% regions set to 0)
- Nearest-neighbor upsampling M = U(M̃)
- Masked spectrum X̃_mask = M ⊙ X̃
- Inverse FFT → X_mask = F⁻¹(X̃_mask) (spatial branch input)
- Masked log-magnitude spectrum (frequency branch input)

### Stage 2: Intra-domain Disentangled Representation Learning
- **Spatial Domain Branch**: ResNet50 backbone + 4 Local Information Blocks (LIBs) + Disentangled Feature Aggregation
- **Frequency Domain Branch**: ResNet50 backbone on spectrum + 4 LIBs + Disentangled Feature Aggregation
- Each LIB uses ResNet34 to extract local features from 2×2 image regions
- Disentanglement loss L_DIS encourages complementary, non-redundant components
- Global information loss L_GIL ensures cross-domain consistency

### Stage 3: Attention-aware Inter-domain Feature Fusion
- F_a = Concat(F_pix, F_freq)
- F_mix = MixBlock(F_a) (two-layer feed-forward + ReLU + dropout)
- Multi-scale pooling: 3×3, 5×5, 7×7 average pooling + global max pooling
- A = σ(MLP(Concat(S_avg³, S_avg⁵, S_avg⁷, S_max)))
- F_att = F_mix ⊙ A
- F = φ(F_att) (FC + ReLU + Dropout)
- Two-layer MLP classifier

### Loss Function
L = L_CE + α·L_DIS + β·L_GIL

where α and β are learnable parameters optimized via uncertainty weighting (Kendall et al., 2018).

## 4. Environment Requirements

### Key Dependencies
- Python >= 3.8
- PyTorch >= 1.10.0
- torchvision >= 0.11.0
- numpy >= 1.21.0
- scikit-learn >= 1.0.0
- Pillow >= 8.0.0
- tqdm >= 4.62.0
- wandb >= 0.12.0 (optional, for training logging)

### Hardware
- NVIDIA GPU with CUDA support (recommended: >= 12GB VRAM)
- CUDA >= 11.0

### Installation
```bash
pip install torch torchvision numpy scikit-learn Pillow tqdm wandb
```

### Training
```bash
python train_enhanced.py \
  --mask_type adaptive_spectral \
  --ratio 15 \
  --use_ddafm \
  --num_epochs 50 \
  --batch_size 32 \
  --lr 0.0001
```

### Testing
```bash
python test_enhanced.py \
  --mask_type adaptive_spectral \
  --ratio 15 \
  --use_ddafm \
  --checkpoint_file <checkpoint_name>.pth
```
